# devin-cli Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Devin API v3 を Bun + TypeScript の CLI (`devin-cli`) から使えるようにし、usage / billing / analytics を最優先コマンドとして提供する。

**Architecture:** docs.devin.ai の各ページに埋め込まれた OpenAPI fragment を `scripts/sync-openapi.ts` で収集・マージして `openapi/devin-v3.yaml` を生成し、Orval (fetch client + custom mutator) で `src/generated/` に型付きクライアントを生成する。CLI は commander 製で `src/commands/` に集約し、HTTP・設定・秘密・エラー処理は `src/lib.ts`（9router-cli 踏襲）に置く。

**Tech Stack:** Bun 1.4.3, TypeScript (tsgo), commander ^12, Orval 8.x (fetch client), oxc (oxlint/oxfmt), yaml, lefthook, bun test。

**Spec:** `docs/superpowers/specs/2026-11-06-devin-cli-design.md`（main にマージ済み。この計画は spec の全要件をタスクに落としたもの）

## Global Constraints

- 言語: Bun + TypeScript。実行は `bun run src/cli.ts`、bin 名は `devin-cli`
- lint/format は oxlint / oxfmt。typecheck は `tsgo --noEmit`
- exit code: 0=成功、1=API が否と答えた、2=使い方・秘密・通信の誤り、70=想定外の内部エラー
- 秘密 (`cog_` トークン) は env `DEVIN_API_KEY` か config `api_key_command` のみ。argv・出力・config 平文に載せない
- consumption/metrics の日境界は UTC-8 固定（08:00 UTC）。`America/Los_Angeles` の夏時間には従わない
- `--days N` は今日を含む N 暦日。`time_after` = 今日(UTC-8)0時の (N-1) 日前、`time_before` = 現在時刻
- 生成物 `openapi/devin-v3.yaml` と `src/generated/` はコミットする。`src/generated/` は oxlint/oxfmt の対象外
- Orval fetch client は `override.fetch.includeHttpResponseReturnType: false`（データを直接返す）
- 参照実装: `/root/.ghq/github.com/TakashiAihara/9router-cli`（src/lib.ts, src/cli.ts, tests/helpers/* を移植元とする）

```ts
// Devin API の消費日は UTC-8 (docs の "midnight PST" = 08:00 UTC) の 0 時で区切られる。
// America/Los_Angeles の夏時間 (PDT=UTC-7) には従わず、UTC-8 固定で計算する
const UTC8_OFFSET_SEC = 8 * 3600;
const DAY_SEC = 86400;

export function utc8DayStart(nowSec: number): number {
  return Math.floor((nowSec - UTC8_OFFSET_SEC) / DAY_SEC) * DAY_SEC + UTC8_OFFSET_SEC;
}

export type Window = { time_after: number; time_before: number };

// 今日を含む days 暦日分。time_after は今日(UTC-8)0時の (days-1) 日前、time_before は現在時刻
export function consumptionWindow(days: number, now: Date): Window {
  const nowSec = Math.floor(now.getTime() / 1000);
  return {
    time_after: utc8DayStart(nowSec) - (days - 1) * DAY_SEC,
    time_before: nowSec,
  };
}

// Unix 秒を UTC-8 の YYYY-MM-DD にする
export function formatDateUtc8(unixSec: number): string {
  return new Date((unixSec - UTC8_OFFSET_SEC) * 1000).toISOString().slice(0, 10);
}
```

```ts
import { existsSync, readFileSync } from "node:fs";
import { homedir } from "node:os";
import { join } from "node:path";

export class ExitError extends Error {
  constructor(
    message: string,
    public code: number,
  ) {
    super(message);
  }
}
export const die = (m: string, code: number): never => {
  throw new ExitError(m, code);
};
export const guard =
  <T>(fn: (o: T) => Promise<number>) =>
  async (o: T): Promise<number> => {
    try {
      return await fn(o);
    } catch (e) {
      if (e instanceof ExitError) {
        process.stderr.write(`${e.message}\n`);
        return e.code;
      }
      throw e;
    }
  };

export class CommError extends ExitError {
  constructor(
    message: string,
    public timedOut: boolean,
  ) {
    super(message, 2);
  }
}

function timeoutMs(env: string, defaultSec: number): number {
  const raw = process.env[env];
  if (raw === undefined) return defaultSec * 1000;
  const n = Number(raw);
  return Number.isFinite(n) && n > 0 ? n * 1000 : die(`${env} は正の秒数にする: ${raw}`, 2);
}

// 2 つの env はテスト用の口ではなく、利用者が設定する口として公開する。
// README と --help に同じ内容を載せる
export const apiTimeoutMs = () => timeoutMs("DEVIN_API_TIMEOUT", 20);
export const commandTimeoutMs = () => timeoutMs("DEVIN_COMMAND_TIMEOUT", 60);

// Devin API の手前に proxy があると、届かなかった時に 502 / 503 / 504 が HTML のエラーページで返る。
// HTTP の応答として届くので区別しないと「相手が否と答えた」(exit 1) と読まれる
const GATEWAY_STATUS = new Set([502, 503, 504]);
const HTML_BODY = /^\s*(?:<!doctype\s+html|<html[\s>])/i;
const isProxyReply = (status: number, raw: string) =>
  GATEWAY_STATUS.has(status) && HTML_BODY.test(raw);

// 通信の失敗だけを ExitError に変える。応答の形の誤りは変換せず cli.ts の想定外 (exit 70) に届ける
export async function send(url: string, init: RequestInit, ms: number) {
  let res: Response;
  let raw: string;
  try {
    res = await fetch(url, { ...init, signal: AbortSignal.timeout(ms) });
    raw = await res.text();
  } catch (e) {
    const timedOut = (e as Error).name === "TimeoutError";
    throw new CommError(
      timedOut
        ? `Devin API が ${ms / 1000} 秒で応答しない: ${url}`
        : `Devin API との通信に失敗: ${(e as Error).message}`,
      timedOut,
    );
  }
  // proxy のエラーページは HTML が何行も詰まるので、本文をそのまま stderr にも出さない
  if (isProxyReply(res.status, raw))
    throw new CommError(
      `Devin API に届かなかった (HTTP ${res.status})。手前の proxy が返した応答で、Devin API 自身の返答ではない: ${url}`,
      false,
    );
  return { status: res.status, statusText: res.statusText, ok: res.ok, headers: res.headers, raw };
}

type Config = { api_key_command?: string; org_id?: string; api_base_url?: string };
function config(): Config {
  const base = process.env.XDG_CONFIG_HOME || join(homedir(), ".config");
  const file = join(base, "devin-cli", "config.toml");
  if (!existsSync(file)) return {};
  let parsed: Record<string, unknown>;
  try {
    parsed = Bun.TOML.parse(readFileSync(file, "utf8")) as Record<string, unknown>;
  } catch (e) {
    return die(`${file} を TOML として読めない: ${(e as Error).message}`, 2);
  }
  for (const key of ["api_key_command", "org_id", "api_base_url"]) {
    if (key in parsed && typeof parsed[key] !== "string")
      die(`${file} の ${key} は文字列にする`, 2);
  }
  return parsed as Config;
}

export function apiBaseUrl(): string {
  const u = process.env.DEVIN_API_BASE_URL || config().api_base_url || "https://api.devin.ai";
  // scheme の無い値は proxy 越しだと 502 の HTML が返り、通信の失敗ではなく相手の否に見える
  if (!/^https?:\/\//.test(u)) return die(`api_base_url は http:// か https:// で始める: ${u}`, 2);
  const url = new URL(u);
  // path 付きの base は endpoint の path と二重になるので origin のみに限定する
  if (url.pathname !== "/")
    return die(`api_base_url は origin のみ (path は含めない): ${u}`, 2);
  return `${url.protocol}//${url.host}`;
}

export function orgIdConfig(): string | undefined {
  return config().org_id;
}

export const API_KEY = "DEVIN_API_KEY";
const CMD_KEY: Record<string, "api_key_command"> = {
  [API_KEY]: "api_key_command",
};

// detached で起動した子が持つプロセスグループをまとめて止める。
// 宛先は直下で起動した子の pid (= その pgid) だけなので、自分のプロセスグループには及ばない。
// Linux はグループにプロセスを残している間その pgid を pid として取らないので、別のグループを誤って指すこともない
function killGroup(pid: number): void {
  // 0 は自分のグループ、負の値は別の番号 (−1 なら全プロセス)。子の pid は自分の pid と同じにならない
  if (pid <= 1 || pid === process.pid) return;
  try {
    // 0 で居ることを確かめてから止める。空のグループは pgid を再利用されうるので、その場合は何もしない
    process.kill(-pid, 0);
    process.kill(-pid, "SIGKILL");
  } catch {
    // 既に止まっていれば (ESRCH) 止める対象も無いので、何もしなくてよい
  }
}

type Command = { timedOut: boolean; code: number | null; out: string; err: string };

// 直下の子が終わった後から pipe の EOF を待つ猶予。
// 孫が pipe を持ったままなら EOF は来ないので、この時間を信じてから孫ごと止める
const EOF_GRACE_MS = 200;

// 待ちを ms で打ち切って null を返す。onTimeout は打ち切りの前に止める対象へ signal を送るため
function deadline<T>(work: Promise<T>, ms: number, onTimeout?: () => void): Promise<T | null> {
  let timer: ReturnType<typeof setTimeout> | undefined;
  const cut = new Promise<null>((resolve) => {
    timer = setTimeout(() => {
      onTimeout?.();
      resolve(null);
    }, ms);
  });
  return Promise.race([work, cut]).finally(() => clearTimeout(timer));
}

// 設定の *_command を走らせて出力を集める。
// 同期実行 (spawnSync) では実行中の JS が動かないので、Ctrl-C を受けて孫まで止める処理が書けない。
// detached で子を別グループにすると signal は子に届かないので、親が先に死んで孫が孤児として残る。
// そこで非同期で走らせ、待つあいだ handler を効かせたままにする
async function runCommand(cmd: string, ms: number): Promise<Command> {
  const proc = Bun.spawn(["sh", "-c", cmd], {
    env: process.env,
    stdin: "ignore",
    stdout: "pipe",
    stderr: "pipe",
    // 子の pid がそのまま pgid になるので、孫をまとめて止めるのに使える
    detached: true,
  });
  const pgid = proc.pid;
  // signal を受けたら先にグループを止めてから終わる。code は signal を素で受けたときと同じ (130 / 143)
  const onSigint = () => {
    killGroup(pgid);
    process.exit(130);
  };
  const onSigterm = () => {
    killGroup(pgid);
    process.exit(143);
  };
  process.on("SIGINT", onSigint);
  process.on("SIGTERM", onSigterm);

  // 出力が大きければ pipe のバッファで子が詰まるので、待つ前に読み始める。
  // 孫を追い払ったあとも出力を捨てずに済むよう、読み終えたら変数に残す
  let out = "";
  let err = "";
  const readOut = new Response(proc.stdout).text().then((t) => (out = t));
  const readErr = new Response(proc.stderr).text().then((t) => (err = t));
  const done = (async () => ({
    code: await proc.exited,
    out: await readOut,
    err: await readErr,
  }))();
  // 打ち切ったあとは待たないことがあるので、握り潰して unhandled にしない
  done.catch(() => {});

  try {
    // 時間切れは直下の子の終了だけで決める。孫が pipe を持ったまま残り続けても待たない
    const code = await deadline(proc.exited, ms, () => killGroup(pgid));
    if (code === null) return { timedOut: true, code: null, out: "", err: "" };

    // 直下の子は終わったので、残りは孫の分。孫が pipe を持ったままだと出力は揃っていても EOF が来ない。
    // 猶予を置いて待ち、待てなければ孫ごと止めてから出力を拾う
    const r = await deadline(done, EOF_GRACE_MS, () => killGroup(pgid));
    if (!r) await deadline(done, EOF_GRACE_MS);
    return { timedOut: false, code, out, err };
  } finally {
    // 正常・失敗・時間切れのどれで終わっても、孫が残っていれば止めておく
    killGroup(pgid);
    process.off("SIGINT", onSigint);
    process.off("SIGTERM", onSigterm);
  }
}

export async function secret(name: string): Promise<string> {
  const v = process.env[name];
  if (v) return v;
  const key = CMD_KEY[name];
  const cmd = key ? config()[key] : undefined;
  if (!cmd) return die(`${name} が env に無く、設定の ${key ?? "*_command"} も無い`, 2);
  const ms = commandTimeoutMs();
  const r = await runCommand(cmd, ms);
  if (r.timedOut) return die(`${name} を ${key} から取れない: ${ms / 1000} 秒で返らない`, 2);
  const out = r.out.replace(/\r?\n$/, "");
  const why = r.err.trim().split("\n").pop() ?? "";
  if (r.code !== 0 || !out)
    return die(`${name} を ${key} から取れない (exit ${r.code}) ${why}`.trimEnd(), 2);
  if (/[\r\n]/.test(out)) return die(`${name} として複数行が返った。値には使わない`, 2);
  return out;
}

// ProblemDetail (RFC 9457) または旧式 {"detail": ...} / {"error": ...} から表示用文字列を取る
export function problemText(raw: string): string {
  try {
    const o = JSON.parse(raw) as Record<string, unknown>;
    for (const k of ["detail", "title"] as const) {
      const v = o?.[k];
      if (typeof v === "string" && v) return v;
    }
    const err = o?.error;
    if (typeof err === "string" && err) return err;
    if (err && typeof err === "object") {
      const m = (err as Record<string, unknown>).message;
      if (typeof m === "string" && m) return m;
    }
    return raw;
  } catch {
    return raw;
  }
}

export const oneLine = (s: string) => s.replace(/[\r\n\t]+/g, " ");
export const cell = (v: unknown) => (v === null || v === undefined ? "-" : String(v));
export const cellText = (v: unknown) => oneLine(cell(v));
export const print = (s: string) => process.stdout.write(`${s}\n`);
export const json = (v: unknown) => print(JSON.stringify(v));

#!/usr/bin/env bun
// docs.devin.ai の v3 API リファレンス各ページに埋め込まれた
// ````yaml v3-openapi.yaml <METHOD> <PATH> フェンスを集めて openapi/devin-v3.yaml を生成する。
// 使い方: bun run sync:openapi
import { mkdirSync, writeFileSync } from "node:fs";
import { dirname } from "node:path";
import { parse, stringify } from "yaml";

export const INDEX_URL = "https://docs.devin.ai/_llms/en/api.txt";
export const OUTPUT_PATH = "openapi/devin-v3.yaml";
export const MIN_PATHS = 50;
const CONCURRENCY = 8;
const SERVER_URL = "https://api.devin.ai";

export function collectUrls(index: string): string[] {
  const urls = new Set<string>();
  for (const m of index.matchAll(
    /^- \[[^\]]*\]\((https:\/\/docs\.devin\.ai\/api-reference\/v3\/[^)\s]+\.md)\)/gm,
  )) {
    urls.add(m[1] as string);
  }
  return [...urls];
}

export type Fragment = { method: string; path: string; doc: Record<string, unknown> };

// フェンス行は ````yaml v3-openapi.yaml GET /v3/self のように method と path が続く。
// 閉じフェンスは ```` (4 つ以上のバッククォート)
export function extractFragment(markdown: string): Fragment | null {
  const lines = markdown.split("\n");
  for (let i = 0; i < lines.length; i++) {
    const m = /^````yaml v3-openapi\.yaml[ \t]+([A-Za-z]+)[ \t]+(\S+?)\s*$/.exec(lines[i] ?? "");
    if (!m) continue;
    const body: string[] = [];
    for (let j = i + 1; j < lines.length; j++) {
      const line = lines[j] ?? "";
      if (/^`{4,}\s*$/.test(line)) break;
      body.push(line);
    }
    const doc = parse(body.join("\n")) as Record<string, unknown>;
    return { method: (m[1] as string).toUpperCase(), path: m[2] as string, doc };
  }
  return null;
}

// キー順を正規化した JSON。fragment 間の「同じ内容か」の比較に使う
function canonical(v: unknown): string {
  if (v === null || typeof v !== "object") return JSON.stringify(v);
  if (Array.isArray(v)) return `[${v.map(canonical).join(",")}]`;
  const o = v as Record<string, unknown>;
  return `{${Object.keys(o)
    .sort()
    .map((k) => `${JSON.stringify(k)}:${canonical(o[k])}`)
    .join(",")}}`;
}

export type MergedSpec = {
  paths: Record<string, Record<string, unknown>>;
  schemas: Record<string, unknown>;
  securitySchemes: Record<string, unknown>;
};

const HTTP_METHODS = new Set(["get", "post", "put", "patch", "delete", "head", "options", "trace"]);

export function mergeFragments(frags: Fragment[]): MergedSpec {
  const paths: MergedSpec["paths"] = {};
  const schemas: MergedSpec["schemas"] = {};
  const securitySchemes: MergedSpec["securitySchemes"] = {};

  for (const frag of frags) {
    const fragPaths = (frag.doc.paths ?? {}) as Record<string, Record<string, unknown>>;
    for (const [p, item] of Object.entries(fragPaths)) {
      const target = (paths[p] ??= {});
      for (const [method, op] of Object.entries(item)) {
        if (!HTTP_METHODS.has(method.toLowerCase())) continue;
        const key = method.toLowerCase();
        const prev = target[key];
        if (prev !== undefined) {
          if (canonical(prev) !== canonical(op))
            throw new Error(`paths ${p} ${method} が fragment 間で内容不一致`);
          continue; // 完全一致なら dedupe
        }
        target[key] = op;
      }
    }
    const components = frag.doc.components as
      | { schemas?: Record<string, unknown>; securitySchemes?: Record<string, unknown> }
      | undefined;
    for (const [name, schema] of Object.entries(components?.schemas ?? {})) {
      const prev = schemas[name];
      if (prev !== undefined) {
        if (canonical(prev) !== canonical(schema))
          throw new Error(`components.schemas.${name} が fragment 間で内容不一致`);
        continue;
      }
      schemas[name] = schema;
    }
    for (const [name, scheme] of Object.entries(components?.securitySchemes ?? {})) {
      const prev = securitySchemes[name];
      if (prev !== undefined) {
        if (canonical(prev) !== canonical(scheme))
          throw new Error(`components.securitySchemes.${name} が fragment 間で内容不一致`);
        continue;
      }
      securitySchemes[name] = scheme;
    }
  }
  return { paths, schemas, securitySchemes };
}

const pascal = (s: string) =>
  s
    .split(/[-_]/)
    .filter(Boolean)
    .map((w) => w.charAt(0).toUpperCase() + w.slice(1))
    .join("");

// GET /v3/organizations/{org_id}/consumption/daily → getOrganizationsOrgIdConsumptionDaily
export function normalizeOperationId(method: string, path: string): string {
  const segs = path
    .replace(/^\/v3\//, "")
    .split("/")
    .filter(Boolean)
    .map((seg) => {
      const inner = /^\{(.+)\}$/.exec(seg)?.[1];
      return pascal(inner ?? seg);
    });
  return method.toLowerCase() + segs.join("");
}

const sortKeys = <T>(o: Record<string, T>): Record<string, T> =>
  Object.fromEntries(Object.entries(o).sort(([a], [b]) => a.localeCompare(b)));

export function buildDocument(merged: MergedSpec): Record<string, unknown> {
  const paths: Record<string, Record<string, unknown>> = {};
  const seen = new Map<string, string>();
  for (const [p, item] of Object.entries(sortKeys(merged.paths))) {
    const methods: Record<string, unknown> = {};
    for (const [method, op] of Object.entries(item)) {
      const o = op as Record<string, unknown>;
      const opId = normalizeOperationId(method, p);
      const prev = seen.get(opId);
      if (prev !== undefined)
        throw new Error(`operationId ${opId} が重複: ${prev} と ${method.toUpperCase()} ${p}`);
      seen.set(opId, `${method.toUpperCase()} ${p}`);
      methods[method] = { ...o, operationId: opId };
    }
    paths[p] = methods;
  }
  return {
    openapi: "3.1.0",
    info: {
      title: "Devin API v3",
      version: "3.0.0",
      description: "Generated from docs.devin.ai v3 API reference by scripts/sync-openapi.ts",
    },
    servers: [{ url: SERVER_URL }],
    security: [{ bearerAuth: [] }],
    paths,
    components: {
      schemas: sortKeys(merged.schemas),
      securitySchemes: sortKeys(merged.securitySchemes),
    },
  };
}

async function fetchText(url: string): Promise<string> {
  const res = await fetch(url);
  if (!res.ok) throw new Error(`${url}: HTTP ${res.status}`);
  return res.text();
}

async function fetchPage(url: string): Promise<Fragment | null> {
  return extractFragment(await fetchText(url));
}

async function pool<T, R>(items: T[], n: number, fn: (t: T) => Promise<R>): Promise<R[]> {
  const out: R[] = new Array(items.length);
  let next = 0;
  await Promise.all(
    Array.from({ length: Math.min(n, items.length) }, async () => {
      while (next < items.length) {
        const i = next++;
        out[i] = await fn(items[i] as T);
      }
    }),
  );
  return out;
}

async function main(): Promise<void> {
  const index = await fetchText(INDEX_URL);
  const urls = collectUrls(index);
  if (urls.length === 0) {
    console.error(`${INDEX_URL} から v3 のページ URL を 1 件も取れなかった`);
    process.exit(1);
  }

  // ネットワーク失敗はリトライ 1 回。フェンスが無いページは skip（数と名前を出す）
  const results = await pool(urls, CONCURRENCY, async (url) => {
    try {
      return await fetchPage(url);
    } catch {
      await Bun.sleep(500);
      return fetchPage(url);
    }
  });

  const frags: Fragment[] = [];
  const skipped: string[] = [];
  results.forEach((frag, i) => {
    if (frag) frags.push(frag);
    else skipped.push(urls[i] as string);
  });
  if (skipped.length > 0) {
    console.log(`skip (OpenAPI フェンス無し) ${skipped.length} ページ:`);
    for (const u of skipped) console.log(`  ${u}`);
  }
  if (frags.length === 0) {
    console.error("OpenAPI fragment を 1 件も抽出できなかった");
    process.exit(1);
  }

  const merged = mergeFragments(frags);
  const pathCount = Object.keys(merged.paths).length;
  if (pathCount < MIN_PATHS) {
    console.error(`抽出した path が ${pathCount} 件で閾値 ${MIN_PATHS} を下回った。docs の形が変わった可能性がある`);
    process.exit(1);
  }

  const doc = buildDocument(merged);
  const yamlText = stringify(doc);
  mkdirSync(dirname(OUTPUT_PATH), { recursive: true });
  writeFileSync(OUTPUT_PATH, yamlText);
  console.log(
    `wrote ${OUTPUT_PATH}: ${urls.length} ページ中 ${frags.length} fragment, ${pathCount} paths, ${Object.keys(merged.schemas).length} schemas`,
  );
}

if (import.meta.main) {
  main().catch((e: unknown) => {
    console.error(e instanceof Error ? e.message : String(e));
    process.exit(1);
  });
}

```ts
import { API_KEY, apiBaseUrl, apiTimeoutMs, ExitError, secret, send } from "../lib.ts";

// Orval が渡す URL を絶対 URL に正規化する。
// 相対 path (/v3/self 等) なら apiBaseUrl() を前置し、絶対 URL なら origin を apiBaseUrl() に差し替える
function absoluteUrl(url: string): string {
  const base = apiBaseUrl();
  if (/^https?:\/\//.test(url)) {
    const u = new URL(url);
    return `${base}${u.pathname}${u.search}`;
  }
  return `${base}${url.startsWith("/") ? url : `/${url}`}`;
}

function problemDetail(raw: string, status: number, statusText: string): string {
  try {
    const o = JSON.parse(raw) as Record<string, unknown>;
    for (const k of ["detail", "title"] as const) {
      const v = o?.[k];
      if (typeof v === "string" && v) return v;
    }
  } catch {
    // JSON でない body は statusText に倒す
  }
  return statusText || `HTTP ${status}`;
}

// Orval fetch client の custom mutator。includeHttpResponseReturnType: false に合わせて
// 成功時はデータ本体を返し、エラーは ExitError として throw する
export async function apiFetch<T>(url: string, options: RequestInit = {}): Promise<T> {
  const headers = new Headers(options.headers);
  headers.set("authorization", `Bearer ${await secret(API_KEY)}`);
  const res = await send(absoluteUrl(url), { ...options, headers }, apiTimeoutMs());
  if (!res.ok) {
    const detail = problemDetail(res.raw, res.status, res.statusText);
    if (res.status === 401)
      throw new ExitError(
        `Devin API が HTTP 401 を返した: ${detail} (DEVIN_API_KEY を確認する)`,
        2,
      );
    throw new ExitError(`Devin API が HTTP ${res.status} を返した: ${detail}`, 1);
  }
  if (res.raw === "") return undefined as T;
  try {
    return JSON.parse(res.raw) as T;
  } catch {
    throw new ExitError(`Devin API の応答を JSON として読めない (HTTP ${res.status})`, 70);
  }
}

import { apiSelf, type SelfResponse } from "./endpoints.ts";
import { die, orgIdConfig } from "../lib.ts";

// /v3/self は 1 プロセス 1 回まで（consumption user の user_id 解決と org 解決で共有する）
let cached: Promise<SelfResponse> | undefined;
export function selfInfo(): Promise<SelfResponse> {
  return (cached ??= apiSelf());
}

// principal_type ごとの org ID 優先順位:
//   pat_user / windsurf_session: primary_billing_org_id → devin_sessions_org_id → org_id
//   service_user / devin_brain:  org_id
// 生成型が const リテラル union とは限らないので Record 経由で防御的に取る
export function orgIdFromSelf(self: SelfResponse): string | undefined {
  const s = self as unknown as Record<string, unknown>;
  const pick = (...keys: string[]) =>
    keys.map((k) => s[k]).find((v): v is string => typeof v === "string" && v.length > 0);
  if (s.principal_type === "pat_user" || s.principal_type === "windsurf_session")
    return pick("primary_billing_org_id", "devin_sessions_org_id", "org_id");
  return pick("org_id");
}

// consumption user で user_id 省略時に使う。service_user には user_id が無い
export function userIdFromSelf(self: SelfResponse): string | undefined {
  const s = self as unknown as Record<string, unknown>;
  const v = s.user_id;
  return typeof v === "string" && v ? v : undefined;
}

export async function resolveOrgId(flag?: string): Promise<string> {
  if (flag) return flag;
  const env = process.env.DEVIN_ORG_ID;
  if (env) return env;
  const cfg = orgIdConfig();
  if (cfg) return cfg;
  const org = orgIdFromSelf(await selfInfo());
  if (org) return org;
  return die(
    "org を解決できない。--org か DEVIN_ORG_ID か config の org_id を指定する",
    2,
  );
}

      new Response(proc.stdout).text(),
      new Response(proc.stderr).text(),
      proc.exited,

    return { code, out, err };

    clearTimeout(killer);

import { consumptionWindow, formatDateUtc8 } from "../dates.ts";
import {
  consumptionDaily,
  consumptionDailyServiceUser,
  consumptionDailySession,
  consumptionDailyUser,
  type ConsumptionResponse,
} from "../api/endpoints.ts";
import { resolveOrgId, selfInfo, userIdFromSelf } from "../api/resolve-org.ts";
import { cellText, die, guard, json, print } from "../lib.ts";

export type ConsumptionOptions = { days: number; org?: string; json: boolean };

// 日別 TSV。billing の日別セクションとも共用する
export function dailyLines(res: ConsumptionResponse): string[] {
  const lines = ["date\tacus\tdevin\tcascade\tterminal\tautomation\treview"];
  const rows = [...res.consumption_by_date].sort((a, b) => a.date - b.date);
  for (const d of rows) {
    const p = d.acus_by_product;
    lines.push(
      [
        formatDateUtc8(d.date),
        d.acus,
        p.devin,
        p.cascade,
        p.terminal,
        cellText(p.automation),
        cellText(p.review),
      ].join("\t"),
    );
  }
  return lines;
}

function emit(res: ConsumptionResponse, asJson: boolean): number {
  if (asJson) {
    json(res);
    return 0;
  }
  for (const line of dailyLines(res)) print(line);
  return 0;
}

export const runConsumptionDaily = guard(async (o: ConsumptionOptions) => {
  const orgId = await resolveOrgId(o.org);
  const res = await consumptionDaily(orgId, consumptionWindow(o.days, new Date()));
  return emit(res, o.json);
});

export const runConsumptionUser = guard(async (o: ConsumptionOptions & { userId?: string }) => {
  const orgId = await resolveOrgId(o.org);
  const userId =
    o.userId ??
    userIdFromSelf(await selfInfo()) ??
    die("user_id を引数で指定する (self の応答に user_id が無い)", 2);
  const res = await consumptionDailyUser(orgId, userId, consumptionWindow(o.days, new Date()));

  async (o: ConsumptionOptions & { serviceUserId: string }) => {
    const orgId = await resolveOrgId(o.org);
    const res = await consumptionDailyServiceUser(
      orgId,
      o.serviceUserId,
      consumptionWindow(o.days, new Date()),
    );
    return emit(res, o.json);
  },
);

export const runConsumptionSession = guard(
  async (o: ConsumptionOptions & { sessionId: string }) => {
    const orgId = await resolveOrgId(o.org);
    const res = await consumptionDailySession(
      orgId,
      o.sessionId,
      consumptionWindow(o.days, new Date()),

```ts
import { consumptionWindow } from "../dates.ts";
import { consumptionDaily } from "../api/endpoints.ts";
import { resolveOrgId } from "../api/resolve-org.ts";
import { dailyLines } from "./consumption.ts";
import { guard, json, print } from "../lib.ts";

export type BillingOptions = { days: number; org?: string; json: boolean };

export const runBilling = guard(async (o: BillingOptions) => {
  const orgId = await resolveOrgId(o.org);
  const win = consumptionWindow(o.days, new Date());
  const res = await consumptionDaily(orgId, win);
  if (o.json) {
    json({ days: o.days, window: win, ...res });
    return 0;
  }
  const sums = { devin: 0, cascade: 0, terminal: 0, automation: 0, review: 0 };
  const seen = { automation: false, review: false };
  for (const d of res.consumption_by_date) {
    const p = d.acus_by_product;
    sums.devin += p.devin;
    sums.cascade += p.cascade;
    sums.terminal += p.terminal;
    if (p.automation !== null && p.automation !== undefined) {
      sums.automation += p.automation;
      seen.automation = true;
    }
    if (p.review !== null && p.review !== undefined) {
      sums.review += p.review;
      seen.review = true;
    }
  }
  print("metric\tvalue");
  print(`days\t${o.days}`);
  print(`total_acus\t${res.total_acus}`);
  print(`acus_devin\t${sums.devin}`);
  print(`acus_cascade\t${sums.cascade}`);
  print(`acus_terminal\t${sums.terminal}`);
  print(`acus_automation\t${seen.automation ? sums.automation : "-"}`);
  print(`acus_review\t${seen.review ? sums.review : "-"}`);
  for (const line of dailyLines(res)) print(line);
  return 0;
});

const emit = (lines: string[], asJson: boolean, body: unknown): number => {
  if (asJson) {
    json(body);
    return 0;
  }
  for (const line of lines) print(line);
  return 0;
};

const usageLines = (u: UsageMetrics): string[] => [
  "sessions_count\tsearches_count\tprs_created_count\tprs_merged_count",
  [u.sessions_count, u.searches_count, u.prs_created_count, u.prs_merged_count].join("\t"),
];

const searchesLines = (s: SearchMetricsResponse): string[] => [
  "searches_created_count",
  String(s.searches_created_count),
];

const PRS_FIELDS = [
  "prs_created_count",
  "prs_opened_count",
  "prs_merged_count",
  "prs_closed_count",
  "prs_taken_over_count",
  "prs_taken_over_opened_count",
  "prs_taken_over_merged_count",
  "prs_taken_over_closed_count",
] as const;

const prsLines = (p: PrMetricsResponse): string[] => {
  const rec = p as unknown as Record<string, unknown>;
  return [PRS_FIELDS.join("\t"), PRS_FIELDS.map((f) => cellText(rec[f])).join("\t")];
};

// sessions はネストした応答なので section/key/value のロング形式で平坦化する
const sessionsLines = (s: SessionMetricsResponse): string[] => {
  const lines = ["section\tkey\tvalue"];
  const rec = s as unknown as Record<string, unknown>;
  const scalars = [
    "sessions_created_count",
    "sessions_created_with_playbook_count",
    "sessions_created_with_search_count",
    "sessions_with_merged_prs_count",
    "avg_acus_per_session",
  ];
  for (const k of scalars) lines.push(["scalar", k, cellText(rec[k])].join("\t"));
  const groups: [string, string][] = [
    ["by_origin", "sessions_created_by_origin"],
    ["by_size_created", "sessions_created_by_size"],
    ["by_size_merged_prs", "sessions_with_merged_prs_by_size"],
  ];
  for (const [section, field] of groups) {
    const obj = rec[field];
    if (obj && typeof obj === "object") {
      for (const [k, v] of Object.entries(obj as Record<string, unknown>))
        lines.push([section, k, cellText(v)].join("\t"));
    }
  }
  return lines;
};

const activeUserLines = (rows: ActiveUserMetrics[]): string[] => {
  const lines = ["start_time\tend_time\tactive_users"];
  for (const r of rows)
    lines.push(
      [formatDateUtc8(r.start_time), formatDateUtc8(r.end_time), r.active_users].join("\t"),
    );
  return lines;
};

export const runMetrics = guard(async (o: MetricsOptions) => {
  const orgId = await resolveOrgId(o.org);
  const win = consumptionWindow(o.days, new Date());
  switch (o.name) {
    case "usage": {
      const res = await metricsUsage(orgId, win);
      return emit(usageLines(res), o.json, res);
    }
    case "searches": {
      const res = await metricsSearches(orgId, win);
      return emit(searchesLines(res), o.json, res);
    }
    case "prs": {
      const res = await metricsPrs(orgId, win);
      return emit(prsLines(res), o.json, res);
    }
    case "sessions": {
      const res = await metricsSessions(orgId, win);
      return emit(sessionsLines(res), o.json, res);
    }
    case "dau":
    case "wau":
    case "mau": {
      const res =
        o.name === "dau"
          ? await metricsDau(orgId, win)
          : o.name === "wau"
            ? await metricsWau(orgId, win)
            : await metricsMau(orgId, win);
      return emit(activeUserLines(res), o.json, res);
    }
    case "active-users": {
      const res = await metricsActiveUsers(orgId, win);
      return emit(activeUserLines([res]), o.json, res);
    }
  }
});
```

注意: `activeUserLines` の引数型は `ActiveUserMetrics[]`。dau/wau/mau の生成戻り値が `ActiveUserMetricsResponse[]` で `ActiveUserMetrics` と同型ならそのまま渡せる。`active-users` は単一オブジェクトなので `[res]` で包む。型が想定と違えば endpoints.ts の型エイリアスを確認して直す。

```markdown
# devin-cli

Devin API v3 を CLI から使うツール。Bun + TypeScript で書かれている。

## 必要なもの

- [Bun](https://bun.sh) 1.4.3 以上
- Devin API の credential（Personal Access Token または Service User key。`cog_` で始まる Bearer token）

## セットアップ

```sh
git clone https://github.com/TakashiAihara/devin-cli.git
cd devin-cli
bun install
```

## 使い方

```sh
bun run start -- --help
bun run start -- self
bun run start -- billing --days 30
bun run start -- consumption daily --days 7
bun run start -- metrics usage --days 30
```

グローバルに使いたい場合は `bun link` するか `bun build --compile` でバイナリを作る（リリースバイナリ配布は今後対応）。

## コマンド

| コマンド | 説明 |
| --- | --- |
| `self` | `GET /v3/self`。認証と principal の確認 |
| `billing [--days N]` | 直近 N 暦日の ACU 消費サマリ（合計・製品別・日別） |
| `consumption daily [--days N]` | 組織の日次消費 |
| `consumption user [user_id] [--days N]` | ユーザーの日次消費（省略時は self の user_id） |
| `consumption service-user <id> [--days N]` | service user の日次消費 |
| `consumption session <id> [--days N]` | session の日次消費 |
| `metrics <name> [--days N]` | `usage` / `sessions` / `prs` / `searches` / `dau` / `wau` / `mau` / `active-users` |

`--org <id>` で org を明示できる。省略時は `--org` > `DEVIN_ORG_ID` > config `org_id` > `GET /v3/self` の順で解決する。

出力は既定で TSV。`--json` で生 JSON。

## 環境変数

| 変数 | 説明 | 既定 |
| --- | --- | --- |
| `DEVIN_API_KEY` | `cog_` トークン（PAT / service user 共通） | 必須 |
| `DEVIN_ORG_ID` | org ID | 省略時は自動解決 |
| `DEVIN_API_BASE_URL` | API の origin | `https://api.devin.ai` |
| `DEVIN_API_TIMEOUT` | API の 1 リクエストあたりの時間切れ（秒） | 20 |
| `DEVIN_COMMAND_TIMEOUT` | 設定の `*_command` の時間切れ（秒） | 60 |

## 設定ファイル

`$XDG_CONFIG_HOME/devin-cli/config.toml`（`XDG_CONFIG_HOME` が無ければ `~/.config/devin-cli/config.toml`）:

```toml
api_key_command = "infisical secrets get DEVIN_API_KEY --plain"  # sh -c で実行、stdout 1 行が秘密
org_id = "org-..."
api_base_url = "https://api.devin.ai"
```

秘密の平文を書くキーは無い。env が `*_command` より優先される。

## 権限

- consumption 系: `ViewOrgConsumption`
- metrics 系: `ViewOrgMetrics`

PAT / service user に権限を付けて発行する。Pro plan (self-serve) では org scope の consumption は使えるが、enterprise scope (`/v3/enterprise/*`) は 403 になる。また metrics の org endpoint はプラン対応が未確認のため、403 が出たら権限不足かプラン非対応かを `detail` で確認する。

## 日付の扱い

consumption / metrics の日境界は UTC-8 固定（Devin docs の "midnight PST" = 08:00 UTC）。`--days N` は今日を含む N 暦日で、`time_after` は UTC-8 の日境界に揃う。`date` フィールドは `YYYY-MM-DD`（UTC-8）で表示する。

## 開発

```sh
bun run check        # typecheck + lint + format:check + test
bun run sync:openapi # docs.devin.ai から OpenAPI spec を再生成
bun run generate     # spec から Orval クライアントを再生成
```

exit code: 0=成功、1=API が否と答えた、2=使い方・秘密・通信の誤り、70=想定外の内部エラー。
```
